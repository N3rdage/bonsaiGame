# Audio

The sound effects (backlog 7-b) and the music (7-c). The effects are one per key of `SOUND_KEYS` in `src/platform/audio.ts`. Each is a short mono 16-bit PCM WAV at 22050 Hz, generated by `art/sounds.mjs` (`npm run art:sounds`): synthesised from sines, sweeps and seeded noise, so a rerun writes byte-identical files, and peak-normalised to half of full scale so none is louder than the others. They are WAV, not Ogg, because the build has no Ogg encoder and WAV decodes in every target browser. Workbox precaches them (`vite.config.ts`).

The music (backlog 7-c), one ambient loop per key of `MUSIC_KEYS`, is WAV for the same reasons: each is an 8 second seamless loop, mono 16-bit PCM at 11025 Hz to keep it small, generated by `art/music.mjs` (`npm run art:music`): slow sine chords under a soft LFO, every frequency a whole number of cycles per loop so the end meets the start, seeded so a rerun writes byte-identical files, and peak-normalised to half of full scale. The lounge, hallway and study share `house.wav`; the title plays no music.
