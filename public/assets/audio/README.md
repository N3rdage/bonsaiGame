# Audio

The sound effects (backlog 7-b), one per key of `SOUND_KEYS` in `src/platform/audio.ts`. Each is a short mono 16-bit PCM WAV at 22050 Hz, generated by `art/sounds.mjs` (`npm run art:sounds`): synthesised from sines, sweeps and seeded noise, so a rerun writes byte-identical files, and peak-normalised to half of full scale so none is louder than the others. They are WAV, not Ogg, because the build has no Ogg encoder and WAV decodes in every target browser. Workbox precaches them (`vite.config.ts`).
